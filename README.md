### AutoFlow AI — Automation Failure Detection & Diagnosis

**Technologies:** Python, FastAPI, Pydantic, pytest  
**Status:** Phase 1 Completed

AutoFlow AI is an automation monitoring and recovery project designed to detect workflow failures, classify errors, and recommend appropriate actions.

**Phase 1 — Completed**
- Built a Python-based failure diagnosis API using FastAPI.
- Implemented structured input validation with Pydantic.
- Added error classification for temporary failures, data errors, authentication issues, and unknown errors.
- Developed rule-based recovery recommendations.
- Verified the initial implementation with **5 passing automated tests**.
